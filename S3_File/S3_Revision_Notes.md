# Revision notes for S3 File

This archive continues to reproduce the five aggregate panels Fig 3B-D, Fig 5D, and Fig 6C. The existing panel code, inputs, and numerical source tables are retained. The current revision adds:

- `Search_Strategies.txt`: copyable expressions transcribed from Fig 1, with the recorded date window and explicit limits on recovering the historical interface filters.
- `Reproducibility_Inventory.csv`: each manuscript panel or table mapped to the files or software outputs available for it, and to limits of the archived record.

No raw or curated record-level WoSCC/Scopus export is redistributed. The package does not claim to reconstruct conversion, merging, screening, name disambiguation, or all network analyses. Those limitations are reported in the manuscript. The original S5 Table local-citation ranking is retained in this revision; no alternative ranking is introduced into S3 File.

The original main Fig 5 composite is retained at the author's request; the earlier panel D replacement was reverted. The retained main figure displays 5 for the PLOS ONE 2017 cumulative count, whereas `Source_Data/Fig5D_Plotted_Data.csv` contains 10. The cumulative source values were independently checked against the 770 retained records. The plotting script recreates those aggregate-data curves, not an exact copy of the retained original composite panel. Neither the source data nor the plotting code was changed to force agreement with the original artwork. The script does not need or redistribute the record-level data.

The root `File_Manifest.csv` is refreshed for this final archive. Each file is listed with a relative path, byte size, and SHA-256. The manifest does not list itself because its own contents determine its hash.
