# Bibliometric figure reproducibility package

This supporting file reproduces five bibliometric figure panels from aggregate
data. It contains the R code and data needed to redraw the panels, rather than
the complete bibliometric search, deduplication, or network-analysis workflow.
Raw database exports and curated record-level datasets are not included.

These are individual panels; they are not the complete composite Figs 3, 5, or 6.
`Figures_TIFF/Fig6C_Author_Production_Over_Time.tiff` is a byte-identical
copy of the manuscript panel supplied as `Figure 6-C.tif`.
PNG previews and the author-panel files with `_Redrawn` in their names are
generated by the R code and are not included in this distribution. The author
redraw uses the manuscript's numeric color-bin labels and layout. The
corresponding citation intervals are documented below and in the plotted
source-data table.

## Run

All four scripts were run with R 4.5.3 on Windows. The entry script warns
if it is launched under a different R version. Package versions are recorded in
`Session_Info/Software_Versions.csv`. Required packages are ggplot2, patchwork,
readxl, and ragg; grid and stats are supplied with R. The author panel uses
ragg for smooth raster rendering and restores the manuscript's year-label
size, axis spacing, numeric color labels, and legend layout. The R redraw
has minor rasterization and legend rendering differences from the manuscript TIFF.

If required, install dependencies once in R:

```r
install.packages(c("ggplot2", "patchwork", "readxl", "ragg"))
```

Extract the entire ZIP before running. Open `run_all.R` in RStudio and use
Source, or run the following from the extracted package directory:

```sh
Rscript --vanilla run_all.R
```

All input and output paths are resolved relative to `run_all.R`. The scripts
in `Code` are called by that entry point. No file picker, database download,
automatic package installation, or Biblioshiny launch is required.
Rerunning creates `Figures_PNG`, generates five PNG panels and the author
panel's `_Redrawn` TIFF, and replaces the other four TIFF panels, source
tables, and session files. The supplied manuscript Fig 6C TIFF is preserved.
The distributed manifest lists all other packaged files and is not
automatically refreshed on rerun.

## Input provenance and meanings

### Annual counts

`Annual_Publication_Counts_2012_2025.csv` transcribes the fourteen annual counts
from the supplied plotting scripts. They sum to 770 publications. It is an
aggregate reconstruction from those scripts, not a newly audited record-level
database export. Cumulative counts are calculated from these annual counts.

The annual trend is fitted by nonlinear least squares to
`publications = a * exp(b * x)`, where `x = year - 2012`, using the R function
`nls` with initial values `a = 14` and `b = 0.17`. The plotted R-squared is
`1 - sum((observed - fitted)^2) / sum((observed - mean(observed))^2)`.

The endpoint compound annual growth rate (CAGR) uses the observed publication
counts `N_2012 = 8` and `N_2025 = 130` over thirteen year-to-year intervals:

```text
CAGR (%) = 100 * [(N_2025 / N_2012)^(1 / 13) - 1] = 23.92%
```

This endpoint rate differs from the constant annual rate implied by the
fitted exponential model:

```text
Fitted annual rate (%) = 100 * [exp(b) - 1] = 18.83%
```

The fitted value `b = 0.172487740454699` is archived in
`Source_Data/Fig3B_Model_Statistics.csv`. The two percentages describe
different calculations and are not interchangeable.

### Lifecycle model

`Lifecycle_Model_Parameters.csv` records the parameters identified in the
original scripts as coming from Biblioshiny: the cumulative asymptote
`K = 5362` publications, midpoint and annual-peak year `t0 = 2033.9`, and
annual peak `271` publications per year. The lifecycle script holds these
parameters fixed and reconstructs the growth constant as
`r = 4 * annual_peak / K = 1084 / 5362 = 0.202163371876166` per year.

For calendar year `t`, the cumulative logistic curve `C(t)` and its annual
derivative `A(t)` are:

```text
C(t) = K / [1 + exp(-r * (t - t0))]
A(t) = dC(t)/dt = K * r * exp(-r * (t - t0)) / [1 + exp(-r * (t - t0))]^2
```

Thus `A(t0) = K * r / 4 = 271` publications per year. The reconstructed
parameters and annual R-squared are archived in
`Source_Data/Fig3CD_Model_Statistics.csv`. The annual R-squared uses the
same residual-to-total sum-of-squares definition as above, evaluated on the
original annual publication counts for 2012-2025.

The package does not refit these lifecycle parameters or independently
validate their original estimation. The retained archive does not provide
a parameter covariance matrix or forecast intervals for this reconstruction.
The reported annual R-squared describes agreement within the observed years;
it is not out-of-sample forecast validation. The projected peak around 2034
and cumulative asymptote are conditional, descriptive extrapolations rather
than validated forecasts. Values after 2025 are model projections, not
observed publications.

### Journal trends

`Journal_Production_Over_Time.xlsx`, sheet `Data`, is the supplied journal
aggregate export dated 20 November 2026, copied without altering workbook
contents. It contains 14 years (2012-2025) and ten journals. Its 140 values
are already cumulative and must not be cumulatively summed again.
The plot reads these values directly; the earlier hand-entered series has
been replaced. All ten 2025 totals agree with manuscript S3 Table.

### Author production

`Author_Production_Over_Time.xlsx`, sheet `Data`, is the supplied author
aggregate export dated 20 November 2026, copied without altering workbook
contents. It contains 72 author-year records for ten authors in 2012-2025.
`freq` is the annual article count and determines bubble area. `TCpY` is
used for color; `TC` is retained in the input as the total citation count.
In this snapshot, all values satisfy `TCpY = TC / (2026 - year + 1)`.
The supplied `TCpY` values are preserved rather than recalculated with the
computer's current year. The color intervals are `[0,20)`, `[20,60)`,
`[60,100)`, `[100,140)`, and `[140,infinity)`. To retain the original manuscript
figure, the legend displays `0`, `40`, `80`, `120`, and `160`, respectively.
These are category labels, not exact citation counts; in particular, `0`
does not mean that every record in that group has zero citations. The
`TC_interval` column in the plotted source data makes the mapping explicit.
Author totals agree with manuscript S4 Table.
Author identifiers are the supplied surname-and-initial labels; this package
does not perform a new author-name disambiguation.

## Submission scope

The package is intended as S3 File, following the TCGA-COAD and GSE42387
reproducibility files. Its caption is provided in the manuscript's Supporting
information section. The archived figures and generated redraws are individual
panels; they do not replace the separate complete main-figure files required
for manuscript submission.

Only aggregate figure inputs are included. Access to underlying Web of Science
and Scopus records remains subject to the respective database terms. This
package does not redistribute those record-level exports.

## Revision and independent rerun

`Search_Strategies.txt` provides the expressions transcribed from Fig 1.
`Reproducibility_Inventory.csv` maps the manuscript items to the available
inputs, scripts, and outputs, and identifies the limits of the archive.
`S3_Revision_Notes.md` describes these additions and documents retention of
the original main Fig 5 composite. Its panel D is not identical to the
aggregate-data redraw: the PLOS ONE 2017 cumulative count is 5 in the retained
main figure and 10 in the archived source data. The source data are unchanged.
The original S5 Table local-citation ranking is retained.

The four scripts were independently rerun on 21 November 2026 with R 4.5.3
and the package versions listed in `Session_Info/Software_Versions.csv`.
All nine numerical CSV files in `Source_Data` were compared with that rerun,
including column names, row order, numeric values, and text values. Numeric
comparisons used relative tolerance 1e-10 and absolute tolerance 1e-12.
This verifies the aggregate plotting workflow; it does not reconstruct the
historical record-level import, screening, or network analyses.
